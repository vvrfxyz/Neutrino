### #10 在线统计批量聚合

1. **repo 层已新增批量聚合接口**
   - `ListUserOnlineStats(ctx, windowSec)` 返回每个用户的在线会话数与设备/IP 数。
   - 统计语义：
     - 会话数：`COUNT(*)`
     - 设备/IP 数：`COUNT(DISTINCT client_ip)`
   - 相关位置：`internal/repo/extensions.go`

2. **在线会话写入语义已与聚合保持一致**
   - `online_sessions` 通过 `(user_id, client_ip, node_id)` upsert。
   - 因此“同 user + 同 IP + 不同 node”会计为多个 session，但仍只算一个 device/IP。
   - 相关位置：`internal/repo/extensions.go`

3. **`/users` 已接入 batched aggregation**
   - `renderIndex` 与 `renderUsersTableOnly` 均通过 `listUsersWithOnlineStats(...)` 注入在线统计。
   - 相关位置：`internal/app/app.go`

4. **用户列表 UI 已显示在线列**
   - 用户表头与行内容均已渲染“在线 / 会话 / 设备/IP”。
   - 相关位置：`internal/app/templates/users.tmpl`、`internal/app/templates/users_table.tmpl`

5. **测试覆盖已补齐**
   - repo 单测：`TestListUserOnlineStats`
   - functional：`TestFunctional_UsersPageShowsBatchedOnlineStats`
   - 相关位置：`internal/repo/extensions_test.go`、`tests/functional/functional_test.go`
